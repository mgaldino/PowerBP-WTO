# Review of International Organizations (RIO) — Submission Guidelines

## LaTeX Template

RIO recomenda usar o Springer template para LaTeX:
https://www.springernature.com/gp/authors/campaigns/latex-author-support

## Figure Numbering

- All figures numbered using Arabic numerals
- Figures cited in text in consecutive numerical order
- Figure parts denoted by lowercase letters (a, b, c, etc.)
- If appendix contains figures, continue consecutive numbering of main text (NOT "A1, A2, A3")
- Figures in online appendices (Supplementary Information) numbered separately

## Figure Captions

- Each figure: concise caption describing accurately what the figure depicts
- Include captions in text file, NOT in figure file
- Begin with **Fig.** in bold, followed by figure number in bold
- No punctuation after number, no punctuation at end of caption
- Identify all elements in figure caption; use boxes, circles, etc. as coordinate points in graphs
- Previously published material: original source as reference citation at end of caption

## Figure Placement and Size

- Submit within body of text (separate only if file size causes upload problems)
- Size figures to fit column width
- Large-sized journals: 84 mm (double-column) or 174 mm (single-column) wide, max 234 mm high
- Small-sized journals: 119 mm wide, max 195 mm high

## Accessibility Requirements

- All figures must have descriptive captions (for text-to-speech/Braille)
- Use patterns in addition to colors for conveying information (colorblind accessibility)
- Figure lettering must have contrast ratio of at least 4.5:1
