# R2 majority conditional interface
Source: architecture_note.Rmd section 2.3, Proposition C2; consumes implementation.md.
At every feasible proposal all weak respondents vote Y. H votes Y iff x_H>=o under T^Y, comparing x_H with max(x_H,o).
Unique optimal proposal: recognized weak i receives one, all others zero.
At the optimum H votes N and implements O; type payoff o.
Before uniform independent recognition every weak value is 1/m, H vector (ell,h).
Values are native R2 and independent of beta and current posterior. Type comparisons also cover posterior-zero types.
Beliefs retain S3; no selection of off-path beliefs is added. Implementation ties after deviations remain a correspondence.
Closed as conditional derivation only; source report contains proof.
